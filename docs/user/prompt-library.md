# Prompt library

The book button beside the composer's attachment button opens your saved prompts. Choose a prompt to insert its text at the cursor. The composer keeps the surrounding draft and does not send the message.

The library starts empty. Use **New prompt** to save a title and prompt text, or **Save current draft** to reuse the current composer's text. Attachments are not included. Each prompt can be edited or deleted from its editor.

Search matches titles and prompt text. The horizontally scrolling tag row filters the list by tag; **All** clears the tag filter. Tags have distinct colors with a solid 2px border and a background at 30% opacity. Assign existing tags or enter comma-separated tags in the prompt editor. Removing a tag from its last prompt removes it from the filter row.

Star a prompt to favorite it. The star beside search toggles the favorites filter. Up and down buttons change manual order, including within a filtered list. Favorites do not override your manual order.

The library belongs to your primary server and is available across projects in the desktop and web clients. Other devices connected to that same server receive saved changes. Separate primary servers keep separate libraries; there is no account-wide synchronization between independent servers. Native mobile has no prompt-library controls yet.

The draft stash is separate: it temporarily holds local drafts, including supported attachments, and is not shared between devices. Saving or inserting a library prompt does not change the stash.
